# Changelog

All notable changes to NoRegretsRVC are documented here.

## [Beta 0.0] - Initial packaged version

- Added the React + TypeScript studio interface.
- Added training project configuration and T4 VRAM estimation.
- Added Applio-based Kaggle notebook generation.
- Added model/workbench, sample conversion, TensorBoard, and settings views.
- Added an Express server for notebook delivery and upstream update checks.
- Added browser-local persistence for supported studio settings.

This is the initial beta snapshot. Features and workflows may change.
